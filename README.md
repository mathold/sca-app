# SCA Analysis & Treatment Plan

เครื่องมือวิเคราะห์พื้นที่และวางแผนการรักษาจัดฟันจากตาราง SCA
อัปโหลดไฟล์ `.xlsx` หรือกรอกค่าเอง แล้วได้แผนการรักษา — ถอน / IPR / ไม่ถอน
พร้อม anchorage, การทำนาย molar และเป้าหมายเมื่อจบการรักษา

**ลิขสิทธิ์ โดย หมอผิ่น**

## การใช้งาน

เปิดเว็บ → ใส่รหัสผ่าน → อัปโหลดตาราง SCA (.xlsx) หรือกรอกค่าเอง → กดคำนวณ → บันทึกเป็น PDF ได้

ติดตั้งลง iPad: เปิดใน Safari → ปุ่มแชร์ → **Add to Home Screen**

## ความเป็นส่วนตัว

**การคำนวณทั้งหมดเกิดในเบราว์เซอร์ของผู้ใช้** ไฟล์และข้อมูลคนไข้ไม่ถูกส่งออกจากเครื่องไปที่ใดทั้งสิ้น
ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มีการเก็บบันทึก
ค่าที่กรอกค้างไว้เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น — กดปุ่ม "ล้างค่า" หรือ "ล็อก" เพื่อลบ

## โครงสร้าง

```

vendor/xlsx.full.min.js SheetJS 0.18.5 — อ่าน .xlsx ในเครื่อง
```

## เวอร์ชัน

เลขเวอร์ชันอยู่ที่หัวไฟล์ `src/report.js` และแสดงบนหน้าจอกับท้ายรายงานทุกใบ
**ต้องแก้ทุกครั้งที่แก้สูตร** เพื่อให้ตรวจได้ว่ารายงานแต่ละใบคำนวณด้วยกติกาเวอร์ชันไหน

หลังอัปโหลดเวอร์ชันใหม่ ให้เปลี่ยนเลข `CACHE` ใน `sw.js` ด้วย ไม่งั้นเครื่องที่เคยเปิดแล้วจะยังใช้ของเก่า

## เปลี่ยนรหัสผ่าน

1. เปิดหน้าเว็บแล้วต่อท้าย URL ด้วย `#hash=รหัสใหม่`
2. หน้าจะแสดงค่า SHA-256 ออกมา คัดลอกไว้
3. วางแทนค่า `PASS_HASH` ใน `index.html` แล้วอัปโหลดใหม่

รหัสถูกเก็บเป็นค่า SHA-256 ไม่ใช่ตัวหนังสือจริง แต่**ไม่ใช่ระบบความปลอดภัยระดับสูง** —
เพราะการคำนวณเกิดในเบราว์เซอร์ คนที่ตั้งใจและรู้วิธียังแกะได้ ใช้กันคนที่บังเอิญเจอลิงก์เท่านั้น
